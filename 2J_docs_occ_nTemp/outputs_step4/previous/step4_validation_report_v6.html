Why calibration adjusts only hom30 — not the other two J3 heads. The J3 model emits three outputs per slot: act30 (14-way activity), hom30 (binary AT_HOME occupancy), and cop30 (9-channel co-presence). Phase-8B raking is a marginal-correction step. It was applied to hom30 alone because that head had a real per-(stratum×slot) marginal error (15.37 pp) in the exact space the Step-5/6 validators score, and it sets the People-present fraction that every downstream gain scales by. The other two heads already met their model gates, so raking them would add inter-head coherence risk for little net benefit (see the “raking all three” discussion below the table).

Section 9 — Addendum: 2005 Cycle Under-Representation in the Census Linkage

Follow-up investigation into the Section 7 “Work by Stratum” chart, where the calibrated 2005 weekday bar (~22% of slots in paid work) sits far below the 2010 / 2015 / 2022 bars (~39%). The root cause is a demographic key-coding gap in the Step-5 census linkage — not a model, activity, or calibration defect. Improved by Task A (2026-07-09) via a REGION-folded Tier-2 match (05_census_linkage.py --region-tier); this section is retained as the v5 diagnostic record, with the Task-A before/after result added below. (An initial Tier-2b design was found same-day to be mathematically incapable of closing the gap — fallback-only placement capped it at 0.47% of agents — and was corrected by merging it into Tier-2 itself; see 9.3.)

9.1 — It is a matching (demand) effect, not a supply shortage

In the diary pool (augmented_diaries.csv), 2005 is the largest cycle, yet it wins the fewest matches against the 286,540 Census-2021 agents. Each Census agent draws one diary via np.random.choice among all diaries matching its demographic cell, through a Tier 1→4 fallback hierarchy (05_census_linkage.py).

9.2 — Root cause: 2005 PR (province) left in legacy 5-region coding

Of the seven match keys (AGEGRP, SEX, MARSTH, HHSIZE, LFTAG, PR, CMA), six overlap the Census for 2005. Only PR is disjoint:

SourcePR values presentOverlap with Census
Census 202110, 24, 35, 46, 48, 59 (StatCan SGC province codes)—
Pool 2010 / 2015 / 202210, 11, 12, 13, 24, 35, 46, 47, 48, 59 (SGC)MATCH
Pool 20051, 2, 3, 4, 5 (legacy GSS 5-region grouping)DISJOINT
Mechanism. Step-2 harmonization mapped PR to SGC codes for 2010 / 2015 / 2022 but left the 2005 cycle in the old GSS 5-region scheme (1 = Atlantic, 2 = Québec, 3 = Ontario, 4 = Prairies, 5 = BC). Because PR appears in both the Tier-1 key set (all 7 keys) and the Tier-2 “core” set (AGEGRP, SEX, LFTAG, PR, DDAY), every 2005 diary fails both — its PR value (1–5) can never equal a Census SGC code (10–59). 2005 diaries become eligible only at Tier-3 (AGEGRP, SEX, DDAY) and Tier-4 (day-type only), where province is dropped.

9.3 — Impact and status

  • Improved by Task A (2026-07-09, corrected same day). Option A (region tier, no fake precision) implemented — Tier-2's geography key folds to a shared REGION_FOLD crosswalk (9.2, below) for all cycles, letting 2005 match at region granularity instead of falling to Tier-3/4. An initial fallback-only Tier-2b design was found, same day, to be structurally capped at 0.47% of agents and was corrected by merging it into Tier-2 itself. 2005's matched share rose 9.03%→15.76% (a genuine near-doubling); Tier-1's count is exactly preserved. Zero validator regressions (see Task A Progress Log). Does not reach the 30.0% pool-supply figure — this is a structural ceiling (Tier-1 permanently excludes 2005 by design; see the Section 9.1 verdict box above), not a remaining bug. The bullets below record the v5 diagnostic (pre-fix) status.
  • BEM aggregate unaffected. hom30 is raked to the exact per-(stratum×slot) AT_HOME marginal after linkage, so occupancy schedules are correct regardless of the cycle mix. no gate impact
  • Two real defects (v5, improved). 2005 was under-weighted ~3× (30% of supply → 9% of matches), and its diaries were placed without province (age/sex only) — any province-specific 2005 signal was scrambled. Combined with the then-un-raked act30, this produced the anomalous 2005 paid-work bar in Section 7 (also addressed by Task B's act30 rake). Task A narrows, but does not eliminate, the first defect (see structural-ceiling note above).
  • Not fully recoverable to exact province. The GSS 2005 PUMF releases only a 5-region variable (not exact province, for confidentiality): Atlantic = NL/PE/NS/NB, Prairies = MB/SK/AB. An exact SGC PR for 2005 cannot be reconstructed — the REGION-folded Tier-2 matches at region granularity only, by design (no synthetic province precision invented).
  • Options (v5 framing, retained for history). (a) crosswalk the 5 regions to province groups and relax the PR match to that grouping; (b) drop PR from the match keys for cross-cycle consistency; or (c) document the caveat. Option A was the one implemented (a shared-region Tier-2, closest in spirit to (a) without inventing province precision).
