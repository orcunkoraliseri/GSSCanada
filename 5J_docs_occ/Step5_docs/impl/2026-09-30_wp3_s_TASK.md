## Manager decisions for this part (operational, written before training; copy them into your state file)
* Outputs are clipped at 0 after de-standardising (loads cannot be negative); this is part of every model, S and C alike.
* Windows (R2): sample (row, day d), d in 0..364; driver hours 24d-168 .. 24d+23 (wrap within the year); target hours 24d .. 24d+23.
  Drivers of the 24 predicted hours ARE inputs (schedules and weather are known inputs, as for EnergyPlus); no target is an input.
* Dynamic channels (normalised with `norm.json`): own presence, appliance fraction, people at home, appliance power; neighbour
  means and flags (same floor, above, below); 7 weather; 5 calendar. Static vector: the `s_*` and `c_*` columns.
* Batches are built from `pairs_development.parquet`: 256 pairs x same day = 512 windows. λ = 0 configurations use the same
  batches and simply drop the pair term, so sampling is identical across the grid.
* Validation loss: a fixed set of 20,000 (validation pair, day) draws (seed 20260930), level MSE + pair MSE both printed every
  epoch; early stopping on their sum (R6), patience 4.
* TCN: input projection, residual blocks of dilated causal Conv1d (kernel 3, dilations doubling 1..128, receptive field > 192 h),
  static vector projected and added at every step, head on the last 24 steps -> 3. small = 8 blocks, large = 16 blocks.
* Transformer: input projection to d_model, learned position embedding (192), static vector as one extra token, encoder layers
  small = 3 / large = 6, 4 heads, feed-forward 4 x d_model, dropout 0.1, head on the last 24 positions -> 3.
* width = d_model or channels {64, 128}. AdamW lr 1e-3, weight decay 1e-4, cosine over 30 epochs x 400,000 windows, bf16
  autocast, seed 1 (torch, numpy, python; `torch.backends.cudnn.deterministic=True`). Stop at 4 GPU-hours keeping the best epoch.
* Data on the GPU: load the store's development and validation arrays to GPU memory once and gather windows by index (fast);
  if 20 GB is not enough, say so in the state file and use pinned CPU memory instead.
