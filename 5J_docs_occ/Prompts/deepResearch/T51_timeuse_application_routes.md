# T51. Time-use diary microdata in Europe that need an application: route, eligibility and time for a Canadian researcher

Paste `00_MASTER_BRIEF_5J.md` first, then `_RESPONSE_TEMPLATE.md`, then this prompt, in one fresh session. **Run it alone.**
Written 2026-10-01 by the 5J manager at the author's request. T49 gives the overall country list; T50 covers files that are
open today; **T51 covers the files that need an application** (scientific-use files, research data centres, Eurostat research
access), so the author can decide which applications are worth filing now.
Your files are `RT51_timeuse_application_routes.md` and `RT51_pages.log` (one line per page or form you opened: URL, what it
was, full / partial / title only, date). Save both in this folder.

## Why we are asking

The study adds a country only with that country's own diaries. France is the known case: the author's Progedo request
n. 38663 was approved for six other files but not for the diary file "lil-1065, Emploi du temps (version pour Eurostat)
2009-2010". The UK file (UK Data Service SN 8128) is held under the End User Licence, whose clause 5 forbids online data tools,
generative AI included, without written permission. We need to know, before filing, which applications can succeed, how long
they take, and whether the terms would allow the study's working method (code written and run with help from cloud AI
assistants; aggregate results published; model weights possibly shared).

The researcher: postdoctoral, Concordia University, Montreal, Canada (outside the EU), non-commercial, sole author.

## What we need, per country and survey (time-use surveys since 2000 whose diary microdata need an application)

Cover at least France (2009-2010 and any newer survey), Germany (2012-2013 and 2022), the Netherlands, Belgium, Austria,
Finland, Poland, Norway, Greece, Romania, Hungary, Estonia and Luxembourg, and add any other country you find. For each:

1. The access scheme and its owner (national statistics office, data archive, research data centre, Eurostat).
2. **Eligibility for a researcher at a non-EU university**, quoted with URL. Is a European co-applicant or host required?
3. The exact application route (form URL, documents, fee) and the stated or typical decision time.
4. **Mode of access:** file sent to the researcher, remote execution, or on-site / secure enclave only. Say whether the mode
   allows running a building energy simulation pipeline on the researcher's own cluster with schedules built from the diaries.
5. Terms, quoted: derived and synthetic data, publication of results and output checking, model weights, and any rule on online
   or AI tools.
6. What the file holds against the study's needs: 10 or 15 minute diary slots, main and secondary activity, location at home,
   all household members or linked household composition, diary day type, region, weights.

Known control (we hold the record): France, Progedo request n. 38663 approved on 2026-09-29 without lil-1065. Report how
lil-1065 is requested today and by whom it is granted; if your route contradicts ours, quote the page.
