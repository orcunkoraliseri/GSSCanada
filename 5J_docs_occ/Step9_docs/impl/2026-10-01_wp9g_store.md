## Input columns (60 on the made-up two-district list; the count depends on the age bands in the two building tables) and their source
* Household (4, from the placement csv series files): presence (`presence_csv`), appl_frac (`appliance_csv`), people = n_members x presence, appl_w = appliance_peak_w x appl_frac
* Neighbour (9, from the placement of the other flats of the same run and the zone map `floor_k`): nb_same / nb_above / nb_below x (people, appl_w, flag); same = flats on the same storey, flat itself excluded; above = storey floor_k + 1; below = floor_k - 1; value = MEAN over the listed flats, flag = 1 if the list is not empty (value 0 then)
* Weather (7, EPW columns 6, 7, 8, 13, 14, 15, 21 of the district year file): dry_bulb_c, dew_point_c, rel_humidity_pct, ghi_wh_m2, dni_wh_m2, dhi_wh_m2, wind_speed_ms
* Calendar (5): hour_sin, hour_cos, doy_sin, doy_cos, dow (Madrid year 2010, Bologna 2014)
* Static (from `static/flats_<D>.csv` and `buildings_<D>.csv`, read by column name): country one-hot s_ctry_es, s_ctry_it; class one-hot s_cls_SFH/TH/MFH/AB; age band one-hot s_age_<band> (bands = union of `age_band_prepared` of both tables); building numeric (z-scored on development, clipped to the development range first): s_storeys, s_flats, s_cond_area, s_u_wall, s_u_roof, s_u_floor, s_u_window, s_shgc_window, s_window_share, s_n_shading; flag s_no_outdoor_wall (raw); flat numeric (z-scored): s_storeys_spanned, s_floor_idx (floor_k), s_floor_area, s_wall_n/e/s/w, s_win_n/e/s/w, s_adiabatic_wall, s_roof_area, s_ground_floor_area; flat flags (raw): s_is_top, s_is_ground
* Never inputs (id columns): run_id, split, district, country, stem, mode, zone, floor, hid, hh_index, nb_* index lists
* Targets (not inputs): heating_kwh, cooling_kwh, equipment_kwh (float32 n x 8760 x 3); total_elec = equipment + (heating + cooling) / 3.0

5. Not in the static tables, therefore NOT inputs yet: units per floor, floor-to-floor height, footprint (E5 lists them). Not available from the two tables; to add when the reader provides them.

8. Flats table written as parquet, with a csv.gz fallback if pyarrow is missing (the pilot used parquet in the same environment, not verified for this env).
