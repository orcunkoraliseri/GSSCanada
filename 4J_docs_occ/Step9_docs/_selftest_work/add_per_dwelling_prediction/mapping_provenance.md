which CREST activity state is **our** correspondence and cannot be cited to anyone. It is
held in `acl_to_crest_activity.csv` so an author ruling edits DATA, never code. Rows whose
join is a name-for-name correspondence between two published code lists are labelled
`VALIDATED`; rows whose join required a judgement are labelled `NOT VALIDATED` and name the
