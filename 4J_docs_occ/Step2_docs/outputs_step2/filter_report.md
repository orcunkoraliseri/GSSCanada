## `act2 = null` is overloaded, and how to tell the two meanings apart

D-S2-12 defines `act2 = null` as "not recorded by the instrument". Given the finding immediately
above (that state never occurs at Step 1's output for any country), **every `act2 = null` row in
`harmonised.parquet` is instead the other case**: a recorded, non-blank `act2_raw` code that did not
map to `crosswalk_activity_secondary.csv` (57 episodes for Spain, 530 for the UK, 0 for Italy — 587
total). A later reader treating `act2 IS NULL` as "the instrument did not field secondary activity"
would be wrong for all 587 of them. The distinction is recoverable from `act2_raw`, which is carried
in `harmonised.parquet` precisely so that it is: `act2_raw == ''` always pairs with `act2 == ''`
(recorded-and-blank, a genuine value); a non-empty, non-null `act2_raw` paired with `act2 IS NULL`
is the unmapped case. No fourth state was added to the schema — the existing `act2_raw` column
already resolves it.
