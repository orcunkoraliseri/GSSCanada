# Build v2 of the 3J submission files (2026-09-25)

Script: `writing/fullSet/assemble_3J_v2.py` (new; `assemble_3J.py` untouched).

## What it does

1. Reads `chapters_v2/00` to `11` in order. The order already matches the 2J AE revision: sections 1 to 6,
   Nomenclature, Appendix A, Appendix B, declarations, References. Nomenclature goes after the Conclusion,
   as in 2J.
2. Front matter goes into 2J AE form. The title becomes a YAML title. Abstract, Highlights and Keywords
   become level-1 headings in the 2J order (the chapter has Keywords before Highlights). The rule is
   dropped. `\textsuperscript{..}` becomes pandoc `^..^`, because raw TeX is dropped in .docx.
3. Each `**Figure N.** *(insert `x.png` here)* caption` becomes `![](path){width=16cm}` with the bold
   caption below it (2J form). The PNG is searched in `submission/figures/` first, then `figures/`, and
   then in `figures/` subfolders with archives skipped. A missing figure aborts the build.
   Figures 5 and 7 come from `writing/figures/` (`../figures/...` in the .md).
4. References get the 2J AE form: a period after `(YYYY)` and a closing period. The 2J `[]{#ref-..}`
   anchors are not added, because 3J citations are not hyperlinked.
5. The SI is built from the "Numbering of supplementary items" table in `SI_additions.md`. Captions
   come from its Content column. The source of each item is fixed in the script and checked against
   the Source column, so a changed plan stops the build.
   - Table S1 = Table_04 and Table S2 = Table_07: everything from `## Sources` to the end of the
     file is not carried. This matches the old SI, which also left out the Table_07 notes section.
   - Table S3 = Table_A1_A2: A1.1 to A1.4 become (a) to (d), and Table A2 becomes (e).
   - Table S4, S.1, S.2 and S.3 come from SI_additions.
   - Figures S1 to S7 are the plan's files.
   - Layout: S.1 to S.3, then the tables, then the figures.
6. Named edits at build time. Each must match exactly once or the build stops. Source files are
   never edited.
   - S1: the intro ("Steps 4-9", "honesty") is rewritten as one plain sentence. "(§3.5)" becomes
     "(Section S.2)". "Provenance key (do not cite...)" becomes "Threshold provenance".
   - S2: the intro is rewritten (see open items). Merge note (rewrite_log Stage 2c item 12): L4
     85.45 becomes 85.36, and the L6 measurement becomes "Not evaluated in the reported runs."
   - S3: "as disclosed in §3.2" becomes "as described in Section S.1".
   - S4: "(Table 4)" becomes "(Table 4 of the main text)".
7. Archive: on the first run, the 4 old outputs were copied to
   `submission/archive/pre_v2_build_2026-09-25/`. Each copy was checked (non-empty, same md5) before
   the original was removed, and `ARCHIVE_COMPLETE.txt` (md5 list) was written. Later runs check that
   manifest and stop if an archived file is missing, empty or changed. The script also refuses to
   archive its own output: .docx files are recognised by their fixed date stamp, .md files by their
   layout.
8. pandoc 3.9 with `ref_submit.docx`, the same reference doc as the 2J AE files (double spacing), with
   fixed `SOURCE_DATE_EPOCH`. Then `post.py` sets tables to 10 pt, single spaced. `ref_submit_single.docx`
   is not used.
9. The checks run on the installed files, read back from disk.

## How to run

```
py -3 writing/fullSet/assemble_3J_v2.py              # build + install + checks
py -3 writing/fullSet/assemble_3J_v2.py --selftest   # broken copies of the installed files; writes nothing
```
Exit codes: 0 = all PASS. 1 = a FAIL in checks 1 to 3. 3 = only check 4 FAILs. 2 = aborted before
install (missing input or figure, archive guard, pandoc image error, or a changed SI plan).
**Expect 3 today** (see check 4).

## How each check was seen failing

`--selftest` ran 21 probes; all 21 were detected. Each one is a deliberately broken copy of an installed file:
- 1a: one image changed by one byte inside the .docx.
- 1b: one image removed from the .docx.
- 1c: an expected caption that does not exist.
- 1e: a real pandoc run on bad TeX math.
- 2a: `(insert` and `⟦` added.
- 2b: an en dash and an em dash added.
- 2c: a real pandoc .docx containing an en dash.
- 2d/2e: "manager", "old Table" and a `.md` file name added.
- 3: Figure 2 renamed to Figure 3; a cite of Figure 12; a cite of Table S9; SI Table S2 renamed S5.
- 4: an unknown citation added; an uncited reference added; the Wilke entry deleted.
- 5 and 6: counts move by +1 [REF NEEDED and +10 words.

Separate one-off runs on temporary copies:
- A missing figure aborts the build.
- A missing image in pandoc aborts the build.
- Archive guard:
  - an empty archive copy stops the build
  - an attempt to archive its own output is refused
  - an archive copy emptied after the manifest is caught
  - an empty current file is refused

**Finding:** the first archive guard missed an empty archive copy. It treated that copy as "not archived"
and overwrote it with the current file. The guard was rewritten (manifest + own-output refusal) and
re-tested before the later runs.
